# ViceCore identity

Original angular interlocking VC monogram. Coral V, sand C.
Colors: coral #ff916f; sand #f6ead4; petrol #0b181b.

vicecore-logo-dark.svg: coral/sand wordmark for dark backgrounds.
vicecore-logo-light.svg: coral/petrol wordmark for light backgrounds.
vicecore-logo-mono.svg: monochrome light wordmark.
vicecore-mark-*.svg: transparent standalone symbols.
All wordmarks are vector outlines; no fonts or external resources required.

Source construction: redesign/brand.py. The VC geometry is original.
Wordmark typography: retained Barlow Condensed ExtraBold, converted to outlines.
