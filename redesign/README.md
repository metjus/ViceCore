Cinematic layout with night-drive artwork, large Barlow Condensed sans-serif titles, DM Sans UI, ink background and lavender accent. Removed italic Playfair headline, geographic slogans, fictional coordinates, issue labels and scroll-driven database panel changes.

Existing art is illustrative fan art, not official game screenshots; this is identified in the hero and footer. No release dates, live community counts or fictitious services were added.

Build: python build.py
Checks: python redesign/verify.py; node --check assets/js/editorial.js; node redesign/verify-interactions.cjs
